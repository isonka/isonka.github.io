# Book Class Skill

Help users book Reformer Pilates, TRX, strength, or cardio at PT Studio 7 Amsterdam.

## Canonical URLs

- Schedule / MindBody booking: https://www.pt7.nl/schedule
- Pricing / packages: https://www.pt7.nl/pricing
- Homepage: https://www.pt7.nl/

## Behavior

1. Send the user to https://www.pt7.nl/schedule to pick a class in the embedded MindBody widget.
2. If they ask about cost first, open https://www.pt7.nl/pricing, then return to schedule.
3. For pregnancy / prenatal clients: prefer private sessions; use https://www.pt7.nl/prenatal-pilates-amsterdam (legacy `/pregnancy-pilates-amsterdam` redirects there).
4. If booking fails or they need help: WhatsApp https://wa.me/31685162693 or email info@pt7.nl / phone +31 685 162693.

## Notes

- Small group classes: maximum **5** participants.
- This site has no machine booking API; booking is via MindBody on the schedule page or direct contact.
