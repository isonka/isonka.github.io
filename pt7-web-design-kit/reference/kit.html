Rules for the web.

  • Breakpoints 1024 (tablet type), 960 (nav collapses, grids 2-up), 720 (phone: app type scale, bottom tab bar, single column).
  • No horizontal scrolling inside sections. The app's coach rail becomes a 2-column grid on phone web.
  • Hero = rounded photo + overlapping cream sheet. On phones it becomes the app hero: edge-to-edge photo, sheet with 32 top corners, −36 overlap.
  • One charcoal feature card per page (Academy or a campaign).
  • Copy in brackets is live data from Mindbody or the admin panel.
  • Buttons are pills, sentence case. Gold pressed → gold-deep.
  • Glass only on floating chrome. Never on cards.
  • Lane colours stay three: Pilates gold, Yoga sage, Strength/TRX orange.
  • Line icons 1.5–1.8 stroke. No emoji, no all caps.
  • Touch targets ≥44. Text contrast ≥4.5:1.
