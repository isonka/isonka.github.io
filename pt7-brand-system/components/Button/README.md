# Button

Gold for the one action the page is for; outline for the alternative; ink for the compact nav button. Poppins Medium, sentence case, square corners.

- **Primary:** `gold` fill, `on-accent` text, `gold-deep` on hover. Once per view.
- **Outline:** 1px `ink` border, transparent.
- **Nav (ink):** `ink` fill, `ground` text — "Book a class" in the header.
- Focus: 2px `focus-ring`, 2px offset. Minimum height 44px.
