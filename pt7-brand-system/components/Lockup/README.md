# Lockup

The PT7 logo: thin-line "PT" in ink with the 7 in gold, dropping below the baseline. It is the only mark. Nothing is added to it — no flame, no slant, no stripes.

- Master: `PT` stroke `ink`, `7` stroke `gold-text` (gold on dark, darker gold on cream). One-colour version: all `ink`, or all black on gold/orange fills.
- Sub-brands: the sub-brand word in Poppins Regular, tracked, under "PT", left-aligned with the P stem — PT7 Academy, PT7 Yoga, later PT7 Strength. Same colour as "PT".
- Circle badge: the logo inside a thin `ink` circle, for avatars, stickers and the door.
- Minimum height 24px. Clear space: the width of the T bar on every side.
- The vector here is a redraw of the supplied PNG; replace it with the original vector file when available.
