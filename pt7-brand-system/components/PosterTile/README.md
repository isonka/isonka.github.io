# Poster tile

Social and print 1:1: logo top-left, one gold 7-stripe top-right, a light two-line headline bottom-left with one medium phrase, one footer line.

- Cream tile for studio posts; charcoal tile for Academy and evening announcements.
- Headline ≤ 6 words, sentence case. No condensed type, no all caps.
- Fixed colours (cream `#f5f0e6`, charcoal `#1c1a18`, gold `#ffd700`) so tiles look the same everywhere.
