Where the
first flame
burned.

1928: Amsterdam hosts the Games and, for the first time, an Olympic flame burns — in a bowl on top of the Marathon Tower. The stadium was built for Olympians. Almost a century later, PT7 trains in the same stadium — unit 15, in the upper-left corner.
